# Bayesian_Statistics_and_Data_Analysis

## Replicating the Use of Historical Data and Bookmakers' Odds in Modeling Football Scores

Project report by Gilbert Annersten, Fabian Lindh and William Jarkander, Department of Statistics, Uppsala University.

Folder: `Football_Scores_vs_Bookmaker_Odds/` (project report and Stan model)

### Abstract

This study replicates a Bayesian hierarchical model derived from "Combining historical data and bookmakers odds in modeling football scores" by Egidi et al. (2018). The paper proposes a new model that combines historical match data with bookmakers odds to estimate and predict match results. The project report replicates the study for the Premier League, one of the four leagues analyzed in the paper. The implementation gave results very similar to those of the article.
